# Token Weather

The first Token Weather product slice: a responsive, interactive dashboard for comparing AI provider conditions.

This is intentionally a frontend-only demo feed. The provider facts are seeded from the research brief and are labeled in the interface so live account collectors and official source ingestion can be added without implying they already exist.

## Run locally

Open `index.html` directly, or serve this folder at the canonical local origin `http://127.0.0.1:4173`:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

## Check

```powershell
npm run check
```
